Gonona

Track tokens. Bridge context across AI chats.

Live usage gauge, prompt tools, and one-click context transfer for ChatGPT, Claude, Gemini, and more.

Install now See how it works

01 — Install

Load Gonona in Chrome or Edge

Developer mode only for now — no store listing required.

Open extensions

Go to chrome://extensions (or edge://extensions).

Enable Developer mode

Toggle Developer mode on in the top-right.

Load unpacked

Click Load unpacked and select this project folder.

Pin Gonona

Open the puzzle menu in the toolbar and pin Gonona for one-click access.

02 — Use

Open a chat, then open the popup

Gonona runs on the page and shows live stats in the toolbar panel.

Visit a supported AI site

Start or continue a conversation on ChatGPT, Claude, Gemini, Grok, Kimi, or GLM.

Click the Gonona icon

See window %, IN/OUT tokens, messages left, and runway pace.

Copy or move context

Copy prompts / Copy context, or send the transcript to another model.

Optimize before you send

Use Optimize prompt to strip filler from the composer text.

03 — Features

What the popup gives you

Token window gauge Percent of the context limit used so far
IN / OUT split User vs assistant tokens from the chat
Messages left Rough runway based on average message size
Context bridge Move a formatted transcript to another AI
Prompt optimizer Local rules only — no API key required
Exact vs estimated Badge flips when provider usage is sniffed

05 — Accuracy

How tokens are counted

ChatGPT uses the vendored GPT tokenizer when available. Claude can show exact totals from SSE usage. Other sites use character heuristics — the popup shows ESTIMATED or EXACT accordingly.
